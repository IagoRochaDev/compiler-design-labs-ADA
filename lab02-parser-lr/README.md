# 📐 Lab 02 - Analisador Sintático (Parser LR)

Este módulo implementa o analisador sintático para a linguagem definida na disciplina. Ele utiliza uma abordagem *bottom-up* (ascendente) baseada em uma tabela de transições LR(1) gerada previamente.
