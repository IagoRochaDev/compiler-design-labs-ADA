# 🛠️ Laboratórios de Compiladores (Linguagem ADA)

Este repositório contém os projetos práticos desenvolvidos durante a disciplina de **Construção de Compiladores**. O objetivo final é a construção modular de um compilador funcional.

## 📁 Estrutura do Repositório

O repositório está organizado de forma modular, onde cada pasta representa uma fase do compilador:

- `lab01-analisador-lexico/`: Tokenização do código-fonte de entrada.
- `lab02-parser-lr/`: Analisador sintático baseado em tabelas LR(1).

## 🔧 Pré-requisitos e Ambiente

Para compilar e rodar os projetos deste repositório, você precisará de:
- **Compilador C++**: GCC (G++ via MSYS2/UCRT64 no Windows ou nativo no Linux/WSL).
- **Gerador de Tabelas**: JSMachines (usado na fase sintática - Lab 02).
